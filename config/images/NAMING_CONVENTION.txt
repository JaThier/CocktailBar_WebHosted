====================================================================
NAMING CONVENTION FÜR COCKTAIL-BILDER
====================================================================

Da GitHub Pages auf Linux-Servern läuft, ist die Groß- und Kleinschreibung 
bei Dateinamen absolut strikt! (Case-sensitive)

1. SPEICHERORT
--------------------------------------------------------------------
- Lege alle Bilder in den Ordner der jeweiligen Bar:
  config/images/<barId>/

  Beispiel:
  config/images/alex/mojito.jpg
  config/images/kollege/gin-tonic.jpg


2. DATEINAMEN & FORMATIERUNG
--------------------------------------------------------------------
- Format: IMMER Kleinschreibung (Lowercase)
- Endung: IMMER .jpg (oder .png), klein geschrieben
- Leerzeichen: Ersetzen durch Bindestrich (-)
- Umlaute & Sonderzeichen: Ersetzen durch ASCII-Zeichen
  - ä -> ae
  - ö -> oe
  - ü -> ue
  - ß -> ss

  Beispiele:
  - "Mojito"              -> mojito.jpg
  - "Sex on the Beach"    -> sex-on-the-beach.jpg
  - "Grüner Engel"        -> gruener-engel.jpg
  - "Tequila Sunrise"     -> tequila-sunrise.jpg


3. VERKNÜPFUNG IM CODE / WEB-UI (ID-BASIS)
--------------------------------------------------------------------
Verknüpfe die Bilder im JavaScript NICHT über den Anzeigenamen, 
sondern über eine bereinigte Cocktail-ID!

Beispiel im Web-UI:
- Name im Formular: "Sex on the Beach"
- Generierte ID:    "sex-on-the-beach"
- Automatische Bild-URL: "config/images/alex/sex-on-the-beach.jpg"
